## 删除安全规则（Windows）

不要自动执行批量删除或递归删除文件/目录的命令，除非用户在执行前明确同意。

未经明确同意，禁止使用：

- `del /s`
  - 递归删除当前目录及子目录中匹配的文件。

- `rd /s`
  - 递归删除目录及其所有子目录和文件。

- `rmdir /s`
  - 与 `rd /s` 类似，递归删除目录树。

- `Remove-Item -Recurse`
  - PowerShell 中递归删除文件或目录。

同时禁止未经确认使用：
- 带通配符的删除命令，例如 `del *.log`、`Remove-Item *.tmp`
- 范围过宽的路径，例如当前目录、项目根目录、用户目录
- 任何等价的批量删除或递归删除命令

如果需要删除文件，只能一次删除一个明确路径的文件。

允许示例：

```powershell
Remove-Item "C:\path\to\file.txt"
```

## 删除安全规则（macOS）

不要自动执行批量删除或递归删除文件/目录的命令，除非用户在执行前明确同意。

未经明确同意，禁止使用：

- `rm -r`
  - 递归删除目录及其内容。

- `rm -rf`
  - 强制递归删除目录及其内容，风险更高。

- `find ... -delete`
  - 按条件批量查找并删除文件。

- `find ... -exec rm`
  - 按条件批量查找并调用 `rm` 删除文件。

同时禁止未经确认使用：
- 带通配符的删除命令，例如 `rm *.log`
- 范围过宽的路径，例如当前目录、项目根目录、用户目录
- 任何等价的批量删除或递归删除命令

如果需要删除文件，只能一次删除一个明确路径的文件。

允许示例：

```bash
rm "/path/to/file.txt"
```
